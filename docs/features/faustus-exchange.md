# 🪙 大宗貨幣交易所 (Faustus Exchange Hub)

在《流亡黯道 2》與《流亡黯道 1》當季更新中，官方推出了全新的黑市 NPC **Faustus 貨幣交易所**。POE_tool 提供原生交易所支援，協助玩家計算手續費、評估大宗掛牌與捕捉跨市場套利機會。

---

## ⚡ 核心能力

### 1. Faustus 官方大宗行情即時同步
- 連線至官方大宗交易 API，取得各類主要通貨（混沌石、神聖石、崇高石、鏡子、路標石/地圖、聖甲蟲）之即時買賣報價深度。
- 提供買價與賣價價差 (Spread) 分析，輔助掌握貨幣流動性。

### 2. 黃金 (Gold) 手續費精算器
- PoE 2 與當代機制中，在 Faustus 進行通貨兌換需要消耗遊戲內黃金。
- 交易所模組內建黃金消耗精算模型：
  - 輸入兌換數量與目標幣種，即時試算所需黃金數量。
  - 避免因身上的黃金不足而導致掛牌或交割失敗。

### 3. 跨市場套利評估器 (Arbitrage Evaluator)
- 自動比對一般市集買家手動密語價格與 Faustus 交易所自動搓合現貨價格。
- 透過矩陣換算計算直接買入與轉手賣出之預估淨利潤（扣除手續費），標記具備套利空間的熱門通貨。
