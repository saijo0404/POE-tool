# ⚔️ 裝備即時查價與詞綴精算 (Price Checker)

POE_tool 的裝備查價模組結合了高效詞綴解析器、中英對照資料庫與官方市集即時查詢引擎，為台服與國際服玩家提供精確的行情分析。

---

## 🔍 核心架構流程

```
[ 遊戲中按 Ctrl+C ]
        │
        ▼
[ 剪貼簿文字抓取 (Win32 Event) ]
        │
        ▼
[ 裝備分類與稀有度解析 (Item Parser) ]
        │
        ▼
[ 詞綴字典中英轉譯與正規化 (Dictionary Engine) ]
        │
        ▼
[ 偽屬性 (Pseudo) 自動合併與價值加權 ]
        │
        ▼
[ 官方市集 API 查詢 (Trade Client) ]
        │
        ▼
[ 價格卡片渲染 (Listing & Currency Stats) ]
```

---

## 🌟 核心特性

### 1. 100% 繁體中文台服詞綴雙向對照
- 內建 17,600+ 詞綴與 5,100+ 物品名稱雙向字典。
- 無論是台服專屬翻譯還是國際服原生物品，均能精準對譯。
- 支援模糊比對，容忍微小文字標點差異。

### 2. 稀有裝備 Pseudo 偽屬性智慧合併
- 自動將「冰冷抗性」、「火焰抗性」、「閃電抗性」聚合成「總元素抗性」。
- 自動將複合生命、力量生命聚合成「總生命」。
- 預設推薦最具交易價值的 2~3 條關鍵詞綴，並允許玩家勾選或取消。

### 3. 數值區間浮動微調 ($\pm 10\% \sim 20\%$)
- 查價介面支援一鍵以目標數值的 80%~90% 作為查詢下限，精確找出同檔次裝備的成交區間。
- 支援詞綴階層 (Tier) 顯示，輔助判斷裝備潛力。

### 4. 智慧速率限制與退避佇列 (Rate Limiter Queue)
- Rust 微核心內建 Tokio 非同步請求佇列。
- 遇到官方 API 429 速率限制時，自動按 GGG 規範之冷卻週期平滑等待與重試，保障帳號連線健康。
